# Interactive 3D Learning Dashboard from Uploaded PDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-grade, responsive academic learning dashboard grounded in uploaded course materials (starting with ICSE Class 10 Biology extracted via PyMuPDF + Windows native OCR fallback) featuring interactive 3D laboratory demonstrations (Three.js), grounded AI assistant, step-by-step problem solver, dynamic question bank generator, practice examination simulator, and analytics.

**Architecture:** A modern decoupled architecture with a Python FastAPI backend providing PDF ingestion, OCR fallback, vector-based semantic retrieval, structured RAG answers, and calculation verification; and a React + TypeScript + Vite frontend with Tailwind CSS, Lucide icons, KaTeX mathematical typography, Three.js 3D simulations, and local SQLite/JSON persistence.

**Tech Stack:**
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Three.js, Lucide React, KaTeX, Canvas Confetti.
- **Backend:** Python 3.14, FastAPI, Uvicorn, PyMuPDF (fitz), Windows Media OCR fallback, Pydantic, Scikit-Learn (TF-IDF & cosine similarity vector search), SQLite.
- **Design System:** Deep wine/burgundy (`#2b1022`, `#4a1525`), electric violet/indigo (`#6366f1`), glassmorphism translucent panels, refined dark/light mode toggles, DM Sans / Nunito / JetBrains Mono typography.

**Spec:** Grounded in uploaded PDF coursework: `Biology - Revision Notes.pdf` (14 chapters, 33 pages), `Biology - Location and Functions.pdf` (11 pages), `Biology - Suggestive Questions.pdf` (8 pages), `Biology - Model Test Paper - 1, 2, 3 (Solved).pdf` (24 pages), and `Biology - Chapterwise Weightage.jpg`.

---

## Global Constraints

- Grounded truth: Every explanation, question, formula, and solution must cite original PDF page numbers.
- Explicit admission of limits: When an inquiry is outside the uploaded documents, state clearly that the source material does not contain the answer.
- Zero placeholder policy: All 13 navigation sections, 3D labs, problem solvers, test engines, and analytics must be fully functional and interactive.
- Both Light & Dark modes supported with WCAG AA compliance (contrast >= 4.5:1).
- PDF upload capability: Students can explore the default ICSE Biology knowledgebase or upload a new PDF document.

---

## Review Focus

1. **OCR Fallback & Scanned PDF Ingestion:** Scanned pages without embedded text layers must fall back seamlessly to OCR extraction while preserving page numbers.
2. **Strict RAG Grounding:** Answers generated by the assistant must cite exact supporting passages and page numbers from the knowledgebase.
3. **Interactive 3D Biological Laboratories:** Three.js scenes (Heart blood flow, Nephron ultrafiltration, Eye vision defect correction, Stomata $K^+$ turgor, DNA double helix) must have real-time controls (sliders, rotation, component isolation, reset).
4. **Step-by-Step Problem Solver:** Numerical and genetic crosses (Punnett squares, Cardiac Output, Net Filtration Pressure) must detail given data, applicable formula, substitution, and mistake warnings.
5. **Persistence & Analytics:** User progress, quiz submissions, bookmarks, and personal notes must persist across reloads in localStorage and backend database.
